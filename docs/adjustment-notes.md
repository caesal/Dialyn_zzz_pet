# 后续调整清单

## 当前造型锚点

- 左右不镜像：紫色电话位于黑发侧，白色长辫位于另一侧。
- 金瞳、黑白中式未来感服装和青绿色饰绳保持一致。
- 环刃在小尺寸动作中允许简化，但不能遮挡脸或穿过身体。
- 背景必须透明，不能保留洋红色抠图边。

## 可以继续改的方向

- 表情：更毒舌、更冷淡或更俏皮。
- 待机：增加接电话、眨眼或轻晃电话线的节奏。
- 跑动：调整速度感、步幅和环刃摆动。
- 失败：改成无奈、吐槽或扶额。
- 等待：改成看手机、拨号或不耐烦地敲脚。
- Review：强化检查任务结果时的专注感。

## 每轮修改要求

1. 先确认要改的状态和目标感觉。
2. 只替换受影响的动作行，避免无关造型漂移。
3. 重组 1536 × 2288 v2 spritesheet。
4. 重新检查透明背景、空帧、跳跃落点和 16 个方向。
5. 更新预览与 `qa/` 报告后再决定是否上传启用。
